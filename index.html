Flame in Free Fall: AI fire risk prediction

NASA Space Apps Challenge, Agadir, 2026. Team project.

A system that predicts fire risk from Apollo 13 mission data and shows how flames behave differently in microgravity and under gravity. It combines a machine-learning classifier, a flame physics model with a 3D visualization, and a NASA-style risk matrix inside a crew-dashboard interface.

My role

Data

Status

HR Email Parser

Independent project, Python.

Turns a messy, hand-collected text list of about 1,700 lines of company HR contacts into a clean, searchable, deduplicated CSV of company, field and email. I built it to replace a fully manual sorting process during my internship search.

My role
Designed and wrote it on my own.
Approach
One parser for each of the seven text layouts, heuristics to separate company names from fields, and a review file for ambiguous or suspicious rows, so that a human only checks the flagged ones instead of the code guessing silently.
Built with
Python 3 (standard library only), regular expressions, Excel for the manual review step.
Code
Private repository, because the source list contains real people’s email addresses. I’m happy to walk through the code on request.
